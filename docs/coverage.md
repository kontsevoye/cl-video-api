# Статус описания API

Последнее исследование: **2026-10-31**. Версия контрактов: **0.2.0**. [Машинный реестр](coverage.json).

Все выявленные публичные функции просмотра, поиска, чтения контента, доставки медиа и гостевого отображения четырёх основных каталогов; отдельно описана связанная упрощённая версия. Модерация, аккаунт и публикации исключены.

В трёх OpenAPI описаны **47 операций**. Статус «проверено» относится к наблюдениям на дату исследования, с ограничениями из таблицы. Он не означает полноту всех серверных маршрутов или проверку всех вариантов данных.

## Что подтверждено и что остаётся открытым

Описание составлено по публичному JavaScript, HTML, анонимным HTTP-запросам и отдельным Chrome-сценариям. При исходной проверке валидированы три OpenAPI, 143 сохранённых ответа, 102 набора параметров, 52 встроенных примера основного API и 5 ограниченных медиа-проб. Это результаты исследования, а не мониторинг доступности сервиса.

- В браузере проверены каталог и пагинация, поиск, фильтр, карточки, фильмографии, циклы, комментарии, тема/список и HLS с перемоткой.
- Проверка скачивания читала не более 64 КиБ. Полное скачивание и все кодеки не проверены.
- `/dav` вернул 403, legacy `/ajax/random/` — 500; рабочая случайная выдача доступна через `/rand`.
- Непустой `additionalFiles` и активные трейлеры не найдены; модель не дополнена догадками.
- URI внешних плееров описаны, но приложения и оборудование не проверены.
- Авторизация, функции аккаунта, публикация, загрузки и модерация исключены.
- SLA, rate limit, срок жизни медиа URL и полнота CORS-политик не установлены.

## Обновление описания

При новой проверке обновите соответствующие OpenAPI, руководство и `coverage.json`: дату, операции, статус и ограничения. Согласуйте эту таблицу с реестром. Запустите `npm run check` и `npm run build`. Автоматическая валидация проверяет документы и ссылки; она не подтверждает работу сервиса и не повышает статус функций.
